# Role skills

Forty roles are in this directory. Start from [the catalog](../catalog/INDEX.md). Deploy the addresses you actually publish.

Every skill loads [the core](../shared/core/SKILL.md). The core defines the claim, the untrusted MIME handling, the human-approval default, and the rule that a skill cannot widen send authority.

Sales, support, projects, and Hello are first in the catalog because a four-role deployment was interviewed. Their reply policies record that fact. The other roles are additional company mailboxes you can adopt. They are not padding copies of those four: billing is not finance, procurement is not vendor management, press is not marketing, and returns is not warranty. Skip the ones you do not run.

To add a role, copy the section list from an existing skill, keep the core link, leave the role human-only in the default policy, and update the catalog and the route example together.
