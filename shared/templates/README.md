# Templates

These files are fictional ACME copy an owner can adopt. They are not transcripts of a live inbox.

The interviews described who was allowed to send. They did not provide reply text. `hello-first-inquiry` is a fixed example body for the narrow Hello grant. The default authorization file does not enable it. Free-form model text is not an automatic-send template.

Placeholders are only `{{organization}}` and `{{role_display}}`. Do not add a placeholder that copies the inbound subject or body.

Artwork URLs are literal HTTPS addresses on `assets.example.com`. Replace them with the operator's public URLs before any real use. Do not switch them to `cid:` attachments.
